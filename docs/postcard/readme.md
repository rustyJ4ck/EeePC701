### Debugging Eee boot process with BIOS post card

What's required:
1. Debug card (Search for: PCI-E LPC PC Analyzer Tester POST Debug Card For Notebook Laptop Express Card)
2. Ribbon cable (Ribbon Flexible Flat Cable 25cm Length 1.0mm 0.5mm Pitch FPC for notebook touchpad)
3. Soldering skills
